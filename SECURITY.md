# Security policy

## Supported versions

Security fixes are provided for the latest version on the `main` branch. This project is currently alpha software.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option in the repository Security tab. Include reproduction steps, affected versions, impact, and any suggested mitigation.

You can expect an initial response within seven days. A fix and disclosure timeline will be coordinated after the report has been validated.
